| Use | Form |
|---|---|
| Public brand | **Voxxai** / **VOX** |
| Short mark | **VOX** |

## Typography

- Display / wordmarks: **Orbitron** (site), heavy geometric sans elsewhere
- UI / body: **Chakra Petch** or system UI sans
- Tone: short, castle-metaphor, Dutch-first for stream chat; EN ok for portfolio

## Voice

- Stream chat / Discord live: “De poort is open”, “Het Kasteel”, ridders — not corporate
- Portfolio: builder voice, dry humor, no hype spam
- Never: AI-assisted development flex on profile; no Spotify now-listening widgets on profile/site
